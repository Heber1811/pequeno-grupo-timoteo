# Modelo de formulário de avaliação

## Apresentação

Você está convidado(a) a avaliar o site Conecta Igreja. A participação é voluntária. Não informe nome, telefone, e-mail ou outros dados pessoais. As respostas serão utilizadas para avaliar e melhorar o projeto acadêmico.

1. Foi fácil navegar pelo site? **Sim / Parcialmente / Não**
2. As informações estavam claras? **Sim / Parcialmente / Não**
3. O site foi útil para encontrar atividades? **Sim / Parcialmente / Não**
4. O que podemos melhorar? **Resposta opcional, até 500 caracteres**

Pode ser aplicado pelo formulário do site ou em Google Forms. Se usar Google Forms, desative coleta automática de e-mail e limite o acesso às respostas.
